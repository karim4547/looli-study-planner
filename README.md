# Looli's Study Planner

A pink, cute study planner: courses and grades with a goal planner, live class tracker, calendar, to-do list, XP and achievements.

This repo holds only the app. It contains no personal data. Courses, marks and the timetable are loaded at runtime from a separate **private** repo, using a read-only access key that is saved only in the user's own browser (Settings → GUC data sync).
